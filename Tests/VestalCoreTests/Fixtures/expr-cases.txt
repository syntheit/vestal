# Expression engine cases. scripts/gen-expr-fixtures.py runs each through
# real jq (1.7.1 unless marked) and writes expr-cases.json, which
# ExprFixtureTests replays against JQExpression.
#
# One expression per line. Directives:
#   @input <json>   input for the following cases (until the next @input/@null)
#   @null           null input (jq -n)
#   @loose          next case: only check that it fails, not the message
#   @jq18           next case: expected output from jq 1.8 (1.8-only builtin)
# Lines starting with '#' are comments.

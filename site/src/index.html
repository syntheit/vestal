vestal

A full-screen dashboard on one key. Press it, glance, press it again. One config draws it on macOS and Linux, and your agent writes the config.

Download the DMG Nix flake

Drawn live by vestal's web renderer from a real config and sample data. Use the arrow keys or swipe to page, as on the real dashboard.

1 · How it works

F3

Press a key

The dashboard covers the screen over a blurred desktop. Set "hotkey" on macOS; on Hyprland the module binds vestal toggle.

17:03

Glance

Time, your machines, the agenda, reviews, builds, markets: one screen, nothing scrolls. More views are pages, a swipe or a number away.

F3

Press it again

It is gone. Hidden, it draws nothing, and sources set to refresh while visible stop fetching.

One config, both systems

~/.config/vestal/config.json

The same file drives the SwiftUI app on macOS and the GTK 4 layer-shell app on Linux. What differs goes under platform. Changes apply as you save.


        

        

          
Nix-native
flake.nix, Home Manager

          
A flake with a Home Manager module: it writes the config from Nix, starts vestal at login, signs the app on your Mac and binds the key in Hyprland.


inputs.vestal.url = "github:syntheit/vestal";

# Home Manager
imports = [ inputs.vestal.homeManagerModules.default ];
programs.vestal = {
  enable = true;
  starter = "developer";
  settings.hotkey = "f3";
  hyprland.enable = true;
};

2 · Starters

      
Pick one on the first run, then reshape it by asking your agent. Each frame is a 16:10 screen: the blurred desktop, the background, the dashboard. Click a frame and use the arrow keys, or swipe, to see its pages.

Tools that answer in JSON

          

            
vestal schema
The config's JSON Schema: every key with its description, default and examples.

            
vestal capabilities --json
What works on this machine: sources, players, calendars, programs on PATH, screenshots, hotkeys.

            
vestal check-config --json
Every finding with a JSON pointer, line, column and a did-you-mean.

            
vestal eval
A jq expression evaluated exactly as a widget would.

            
vestal render
The screen as an outline of node ids and texts, or the full render model with --json.

            
vestal screenshot
A PNG drawn by the real renderer, offscreen, with clipped and truncated nodes counted.

            
vestal gallery
Every preset's sample drawn, so an agent can see a widget before adding it.

6 · Install

      

        

          
Homebrew

          
Installs Vestal.app and a vestal command.

          
        

        

          
DMG

          
Signed and notarized. macOS 14 or later, Apple silicon and Intel. Drag Vestal.app to Applications and open it once.

          GitHub releases
        

        

          
Nix flake

          
macOS or Linux, through Home Manager. Nix users need neither the DMG nor the cask.


inputs.vestal.url = "github:syntheit/vestal";
programs.vestal.enable = true;

        

        

          
Linux

          
NixOS with Hyprland today: a GTK 4 layer-shell window and a systemd user service. Wayland has no global hotkeys, so the module binds vestal toggle for you.


programs.vestal.hyprland.enable = true;

        

      

      
Then start from a starter, vestal init --starter developer, set "hotkey", and ask your agent for the rest.

vestal

vestal is a full-screen dashboard that a hotkey shows and hides. The same JSON config draws it on macOS and on Linux, and the binary includes the docs and checks a coding agent needs to write that config for you.

Download the DMG Nix flake

Three of the starters, drawn live by vestal's web renderer from their configs and sample data.

How it works

F3

Show it with a hotkey

The dashboard covers the screen over a blurred copy of your desktop. On macOS you set the key with "hotkey"; on Hyprland the Home Manager module binds vestal toggle.

17:03

Read it on one screen

It shows the widgets in your config, such as the time, your machines, the agenda, pull requests, builds or markets, on a screen that does not scroll. Further views are pages you reach with a swipe or a number key.

F3

Hide it with the same key

While hidden, vestal draws nothing, and sources set to refresh only while the dashboard is visible stop fetching.

One config for macOS and Linux

~/.config/vestal/config.json

The same file drives the SwiftUI app on macOS and the GTK 4 layer-shell app on Linux. Settings that differ between the two go under platform, and changes apply when you save.


        

        

          
A Nix flake
flake.nix, Home Manager

          
The flake has a Home Manager module that writes the config from Nix, starts vestal at login, signs the app on your Mac and binds the key in Hyprland.


inputs.vestal.url = "github:syntheit/vestal";

# Home Manager
imports = [ inputs.vestal.homeManagerModules.default ];
programs.vestal = {
  enable = true;
  starter = "developer";
  settings.hotkey = "f3";
  hyprland.enable = true;
};

        

      


      
Asking an agent for a change
vestal has no settings window. You describe the change, and the agent edits the JSON and checks it with the vestal binary.

      

        
        
        

        

        

      

      
Each result is drawn from a config and sample data in the repository (Resources/samples/agent-*), and the command output is from runs against them.

    

  


  

    

      
Starters

      
A starter is a complete dashboard to begin from. Pick one on the first run, then change it by hand or by asking your agent. Each frame shows a 16:10 screen with the blurred desktop, the starter's background and its dashboard. Use the tabs under a frame or swipe to see its pages, and click a frame to see it full size.

      

    

  


  

    

      
Widgets

      
These are all of the widget presets, each drawn at its real size from its sample data. A card names the data source and gives the JSON that adds the widget to a config.

      

      

    

  


  

    

      
Backgrounds

      
A background draws between the blurred desktop and the dashboard. Each one is a shader in Resources/shaders, and macOS, Linux and this page draw the same files. Use "Dashboard over it" to check how text reads on top. No background draws while vestal is hidden. The power use under each name says how hard it works the machine while the dashboard is shown; measured headless on Apple silicon at 30 frames a second, each one here stayed around 1 % of the CPU.

The binary includes the documentation, the config's JSON Schema, a checker and an offscreen renderer, and the commands an agent uses can print JSON. Commands with JSON output

          

            
vestal schema
The config's JSON Schema: every key with its description, default and examples.

            
vestal capabilities --json
What works on this machine: sources, players, calendars, programs on PATH, screenshots, hotkeys.

            
vestal check-config --json
Every finding with a JSON pointer, line, column and a did-you-mean.

            
vestal eval
A jq expression evaluated exactly as a widget would.

            
vestal render
The screen as an outline of node ids and texts, or the full render model with --json.

            
vestal screenshot
A PNG drawn by the real renderer, offscreen, with clipped and truncated nodes counted.

            
vestal gallery
Every preset's sample drawn, so an agent can see a widget before adding it.

          

          
Read AGENTS.md llms.txt llms-full.txt

          
An agent on the web can start from llms.txt, an index of the docs as Markdown, or read all of them at once in llms-full.txt.

        

      

    

  


  

    

      
Install

      
vestal is a Mac app first and needs macOS 14 or later, on Apple silicon or Intel. On Linux the same config runs through Nix. Homebrew is the easiest way to install it on a Mac and keep it updated.

      

        

          
Homebrew

          
Installs Vestal.app and a vestal command. brew upgrade --cask vestal updates it.

          
        

        

          
DMG

          
Signed and notarized. Drag Vestal.app to Applications and open it once; it has no Dock icon and stays resident while hidden.

          Download from GitHub releases
        

      


      

        
First run

        
    
          
  1. Pick a starter. vestal init writes the default dashboard to ~/.config/vestal/config.json; vestal init --list shows all eight and vestal init --starter developer picks one. It prints what that starter needs from you.
    2. 
          
  2. Press the hotkey. Every starter sets "hotkey": "cmd+shift+space", which shows the dashboard and hides it again. Change it in the config ("f3" works too); the file reloads as you save.
    3. 
          
  3. Allow the two permissions macOS asks for: Calendar, the first time the agenda reads your events, and Automation, the first time the media widget talks to Music or Spotify. Nothing else needs a permission.
    4. 
          
  4. To start vestal at login, run vestal login-item on.
    5. 
        

        
Then ask your agent for the rest, or follow Your first dashboard by hand.

      


      

        

          
Nix and Home Manager
macOS or NixOS

          
The flake's Home Manager module writes the config from Nix, starts vestal at login and signs the app on your Mac. Nix users need neither the DMG nor the cask.


inputs.vestal.url = "github:syntheit/vestal";

imports = [ inputs.vestal.homeManagerModules.default ];
programs.vestal = {
  enable = true;
  starter = "developer";
  settings.hotkey = "cmd+shift+space";
};

        

        

          
NixOS with Hyprland

          
On Linux vestal is a GTK 4 layer-shell window and a systemd user service. Wayland has no global hotkeys, so the module binds vestal toggle in Hyprland for you.


programs.vestal.hyprland.enable = true;

        

      

      
On Linux, vestal runs today on NixOS with a layer-shell compositor such as Hyprland. Packages for other distributions are planned.

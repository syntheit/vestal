# vestal web renderer

A third renderer for the render model (`vestal docs render-model`), next to SwiftUI and GTK. Dependency-free ES modules, no bundler, works from any static file server. Nodes are DOM and CSS (text stays crisp and selectable); drawn nodes (bars, rings, sparklines, charts) are inline SVG; backgrounds are WebGL2.

## API

```js
import { mount } from "./renderer/index.js";

const view = mount(element, snapshot, {
  size: { width: 760, height: 860 },   // screen size in points; default: the element's size, tracked
  scale: 1,                            // CSS pixels per point
  background: "auto",                  // "auto" (theme.background), "aurora", "blur", "none", a shader name,
                                       // { name, color, wallpaper }, or (snapshot) => one of these
  onInput: (msg) => {},                // { cmd: "invoke", id } | { cmd: "key", key } | { cmd: "page", step } | { cmd: "snapshot" }
  views: { main: snapA, focus: snapB },// optional: lets the mount page between views by itself (static sites)
  assets: { icons: "/fonts/", fonts: "/typefaces/", shaders: "/shaders/" },
  resolveImage: (path) => url,         // `image` nodes; without it they draw the empty state
  observe: true,                       // false: the host says when the mount is on screen (setMotion)
  motion: { visible: true, background: true, coarse: false },
});

view.update(patch);      // a patch, a snapshot, or an array of messages; false: ask for a fresh snapshot
view.setMotion({ visible, background, coarse });  // on screen; background moving or a still frame; hands once a minute
view.addViews({ name: snapshot });                // more views to page to
view.destroy();
```

By default a mount watches whether it is on screen and moves only then. A page with many mounts can pass `observe: false` and report it with `setMotion({ visible })` (the site's mount manager does). `background: false` draws one still frame; `coarse` moves every clock hand once a minute (reduced motion, data saver). A `background` function gives views a look of their own (the site's hero pages through starters); a new background with a new view crossfades.

`update` follows "Patches" in `docs/reference/render-model.md`: ops apply in order, a `base` that is not the last `seq` returns `false` and sends `{cmd: "snapshot"}` through `onInput`. A change of `view` animates (slide, fade or none, 250/180 ms, fade under reduced motion). Dots, the popup (scrim and card) and the transition come from the model.

Input: clicks on `action` nodes send `invoke`; keys (in the key grammar) go as `key` while the mount is focused; a pointer drag or two-finger scroll swipes pages with the native thresholds and sends `page`. The static site acts on none of these unless it passes `views`, which makes arrows, tab and view keys switch locally. A `vestal subscribe` bridge would feed `update` and forward `onInput`.

## Files

| File | |
|---|---|
| `renderer/layout.js` | The normative layout rules, pure (a port of the SwiftUI arithmetic). Text is measured through a callback. |
| `renderer/text.js` | Font stacks (the `display`, `sans`, `mono` and `rounded` roles, or a family name), canvas text measuring, word wrap. |
| `renderer/typefaces.js` | `@font-face` rules for the families in `Resources/fonts/`, loaded from `assets.fonts` (default `Resources/fonts/`); the renderer lays out again once they load. |
| `renderer/dom.js` | Node DOM, reconciled by node id. |
| `renderer/draw.js` | SVG for `bar`, `ring`, `spark`, `divider`, `bars`, `stackedBar`, `heatmap`, `timeline`, `analog`. |
| `renderer/clock.js` | The clock faces: analog (SVG, hands turned by a driver that runs only while the mount is on screen, every face on the page from one shared timer), flip (DOM tiles folded with the Web Animations API), the ring's ticks, labels and dot. The pure arithmetic mirrors `ClockFaces.swift`. |
| `renderer/backgrounds.js` | Shared WebGL2 context and frame loop, aurora, shader loader. |
| `renderer/pages.js`, `patch.js`, `color.js` | Paging and swipe, patches, palette. |
| `renderer/icons.js` | Generated by `python3 nix/gen-iconmap.py` (same table as `IconMap.swift`). |

## Backgrounds

`aurora` is built in (a port of `AuroraView.metal`). Any other name loads `<assets.shaders><name>.glsl` (default `Resources/shaders/`) and falls back to the aurora when the file is missing or does not compile. `blur` draws the palette `bg` (over a blurred `wallpaper` at `theme.dim` when one is given), `none` is transparent. Shader files are GLSL ES 3.00 fragment bodies: without a `#version` line they get a prelude (`uv`, `o`, `uRes`, `uTime`, `uP`, `hash`, `vnoise`, `fbm`, `hsv2rgb`); with one they are used as is. The library backgrounds (`mesh`, `topo`, `rain`, `sky`, ...) are the exception: they load `common.glsl` plus their body and use `resolution`, `time`, `p` and `c0` to `c3` (fixed defaults here). Surfaces pause when off screen, when set still, and under `prefers-reduced-motion`, and the one requestAnimationFrame loop stops while none moves.

## Gallery

```sh
swift build -c release
node web/build-gallery.mjs [--vestal .build/release/vestal] [--only clock aiUsage]
python3 -m http.server -d web 8000     # http://localhost:8000/gallery/   (?bg=blur, ?scale=2)
```

The script runs `vestal render --json --config … --data … --at …` for every sample in `Resources/samples/` (TZ UTC, 24-hour locale, as `vestal gallery`), and writes `web/gallery/` (`index.html`, `data.json`, copied fonts and shaders; git-ignored). Deploy `web/` as a whole: the page imports `../renderer/`.

## Tests

```sh
node --test web/renderer/*.test.mjs
```

Layout math (with a fixed-pitch fake measurer), patches, icon map against the bundled CSS, paging and swipe, drawing helpers. Not in the Nix flake checks (the closure has no node); run them by hand.

## Limits

- Fonts: the system stacks. Without SF (Linux, headless browsers) text is a little narrower or wider than native and line heights differ by a pixel or so; weight 100 to 300 may render as regular. Layout matches in structure, as the render model promises.
- Icons are always the Phosphor font (`theme.icons.mode: native` SF Symbols do not exist here; `sf:` names draw nothing).
- `image` paths are paths on the machine running vestal; use `resolveImage`.
- Hairlines (0.5 pt dividers) render as one device pixel; macOS at 1x can drop them.
- No blur of the real desktop: `blur` is a flat or wallpaper-based stand-in.
